# Customer Churn Prediction Using ML

This project predicts whether a customer will leave (churn) a service using Machine Learning algorithms.

## 📊 Project Overview
- Objective: To predict customer churn to help businesses retain customers.
- Techniques Used: Data Preprocessing, EDA, Machine Learning Classification Models
- Tools: Python, Pandas, Scikit-learn
